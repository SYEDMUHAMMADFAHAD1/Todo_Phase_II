# Evolution of Todo – Phase II (Full-Stack Web Application)

## Overview
This is a modern multi-user web application built using strict Spec-Driven Development with Claude Code and Spec-Kit Plus. The project follows the principles defined in the project constitution, transforming the previous console app into a secure, scalable web platform.

## Project Principles
This project adheres to the following core principles as defined in `.specify/memory/constitution.md`:

1. **Correctness-first backend and frontend behavior**
2. **Security-by-design with strict user isolation**
3. **Spec-driven development with traceable requirements**
4. **Clear separation of concerns (frontend, backend, auth, data)**
5. **Production-grade architecture suitable for real users**

## Technology Stack
- **Frontend**: Next.js 16+ (App Router)
- **Backend**: Python FastAPI
- **Database**: Neon Serverless PostgreSQL
- **Authentication**: Better Auth + JWT

## Project Structure
```
/specs              # Feature specifications, plans, and tasks
/backend            # FastAPI backend source code
/frontend           # Next.js frontend source code
/.specify           # Spec-Kit Plus configuration and templates
/history            # Prompt History Records and ADRs
```

## Getting Started
1. All development starts with updating specifications in `/specs`
2. Implementation follows the Spec-Driven Development methodology
3. All code changes must comply with the project constitution

## Development Workflow
- Specs are the single source of truth
- All code must be generated by Claude Code
- Follow strict security and isolation standards
- Enforce separation of concerns across the full stack

DIAGNOSTIC STEPS
================

Step 1: Check Backend
  Command: curl http://localhost:8000/health
  Expected: {"status":"ok"}
  If fails: Backend not running

Step 2: Check Frontend URL
  Console: console.log(process.env.NEXT_PUBLIC_API_URL)
  Expected: http://localhost:8000/api
  If wrong: Update .env.local

Step 3: Check Network Request
  DevTools: Network tab → POST /api/auth/signup
  Look for:
    - Status code (200 = success)
    - Request body has email, password, name
    - Response has user, session, token

Step 4: Check Console Output
  DevTools: Console tab
  Look for emoji signals (🔐 📡 ✅)
  If only sees error: Check error message

Step 5: Check Token Storage
  Console: localStorage.getItem('todo_app_token')
  Expected: Long string starting with "eyJ"
  If null: Token not being stored

Step 6: Check AuthContext State
  Console: Refresh page and check if still logged in
  If not: AuthContext not persisting state correctly

BACKEND VERIFICATION
====================

Test 1: Health Check
  curl http://localhost:8000/health
  Expected: {"status":"ok"}

Test 2: Database Connection
  ls backend/todo_app.db
  Expected: File exists and has size > 0

Test 3: CORS Headers

    -H "Content-Type: application/json" \

  Expected response headers:
    HTTP/1.1 200 or 409
    Access-Control-Allow-Origin: *

Test 4: Create User via CLI

ERROR RECOVERY
==============

If stuck, try in order:

1. Hard refresh frontend (Ctrl+Shift+R or Cmd+Shift+R)
2. Clear browser cache (DevTools → Network → Disable cache)
3. Clear localStorage
   console.clear()
   localStorage.clear()
   location.reload()
4. Restart backend
   Kill process on port 8000
   python -m backend.run_server
5. Restart frontend
   npm run dev
6. Check database
   rm backend/todo_app.db (will recreate)
   Restart backend
